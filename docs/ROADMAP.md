# Roadmap

1. Define and test an orthonormal Zernike basis through radial order 10 and publish
   an explicit mode convention/conversion table.
2. Implement photon-count and read-noise models with unit and calibration tests.
3. Add coefficient fitting, sampling controls, and failure detection.
4. Extend the runner to the preregistered factorial grid and full provenance schema.
5. Add generated figure suite and statistical reporting.
6. Run and archive the complete benchmark; report both positive and negative cases.
7. Design any external telescope validation as a separate protocol; none is implied
   by synthetic results.
