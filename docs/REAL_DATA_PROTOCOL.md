# Real-data protocol

**Status: UNRUN.** No real telescope dataset or observational recording has been
processed. No external measurement, licence, sensor geometry, pupil definition, or
ground-truth wavefront is available for a real-data validation protocol.

Any future real-data work requires a documented data source and licence, raw-frame
checksums, wavelength and bandwidth, effective pixel pitch, camera calibration,
pupil geometry and registration, acquisition metadata, independent focus/wavefront
ground truth, predeclared preprocessing, fixed reconstruction/noise models, and
repeatability across acquisitions. Synthetic model parameters must not be presented
as observed telescope conditions.

No claim of telescope, adaptive-optics, atmospheric, astronomical, or observatory
performance follows from the present synthetic simulations.
